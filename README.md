# Tomato Value Chain Challenges

Research and analysis materials for a project on challenges in the tomato value chain and tomato marketing channels.

## Repository contents

- `proposal final[1].docx` — project proposal
- `Project 4.2.docx` — project document
- `project 4.1 submission corrections (2).docx` — submission corrections
- `Presentation slides (1).pptx` — presentation slides
- `tobit_results.xlsx` — Tobit model results
- `OBJECTIVE1AND2.spv` — SPSS output for Objectives 1 and 2

## Data

Raw respondent-level data files are not included in this public repository.
